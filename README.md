# Modern Developer Portfolio 🚀

A modern, responsive, and minimalist developer portfolio built with semantic **HTML5**, **Tailwind CSS**, and dynamic **vanilla JavaScript**. Designed with a sleek Dark Slate theme inspired by modern developer ecosystems.

---

## 🌟 Key Highlights

- **Dark Slate Aesthetic:** Modern `#0B0F17` dark UI with ambient blue glow effects and crisp border contrasts.
- **Dynamic Project Showcase:** Scalable data-driven project architecture rendered dynamically via JavaScript.
- **Dual Action Links:** Direct routing to live deployments (Vercel / Hugging Face) and GitHub source code repositories.
- **Responsive Layout:** Optimized across desktop, tablet, and mobile views with a slide-over mobile drawer menu.
- **Zero Heavy Dependencies:** Lightweight and fast load times without heavy bundling frameworks.

---

## 🛠️ Built With

- **HTML5:** Clean, semantic structure.
- **Tailwind CSS (CDN):** Modern utility-first styling and custom design extensions.
- **JavaScript (ES6+):** Dynamic DOM injection and interactive UI event handling.
- **Google Fonts:** Plus Jakarta Sans for clean typography.
